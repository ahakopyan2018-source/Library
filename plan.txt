==================================================
PROJECT PLAN: LIBRARY MANAGEMENT APP
==================================================

1. What is the app for, in one sentence?
Այս հավելվածը նախատեսված է փոքրիկ թաղամասային գրադարանի թղթային գրանցամատյանը թվայնացնելու, գրքերի շրջանառությունը (ավելացում, վերցնում, վերադարձ, ջնջում), որոնումն ու կարգավիճակների վերահսկումն ավտոմատացնելու համար[cite: 1, 2].

2. Who uses it?
Հավելվածից օգտվելու է տեղի գրադարանավարը[cite: 1].

3. What information do we keep about a book?
- Վերնագիր (Title - պարտադիր)[cite: 2]
- Հեղինակ (Author - պարտադիր)[cite: 2]
- Տարեթիվ (Year - կամընտիր)[cite: 2]
- Կարգավիճակ (Status: Available / Borrowed)[cite: 2]
- Վերցնողի անուն (Borrower name - առկայության դեպքում)[cite: 2]
- Վերցրած ամսաթիվ (Borrow date)[cite: 2]
- Վերադարձի վերջնաժամկետ (Due date - 14 օր անց)[cite: 2]

4. What can the user do? (list the actions)
- Ավելացնել նոր գիրք[cite: 2]
- Դիտել բոլոր գրքերի ցանկը՝ իրենց ընթացիկ կարգավիճակներով[cite: 2]
- Վերցնել գիրք (նշելով վերցնողի անունը, ավտոմատ գրանցելով ընթացիկ և +14 օր վերադարձի ժամկետները)[cite: 2]
- Վերադարձնել գիրք (կարգավիճակը դարձնելով հասանելի, մաքրելով վերցնողի անունն ու ամսաթվերը)[cite: 3]
- Խմբագրել գրքի տվյալները (վերնագիր, հեղինակ, տարեթիվ՝ պահպանելով ընթացիկ կարգավիճակը)[cite: 3]
- Ջնջել գիրք (նախնական հաստատման հարցումով "Are you sure?")[cite: 3]
- Որոնել գրքեր ըստ վերնագրի կամ հեղինակի (անտեսելով մեծատառ/փոքրատառ տարբերությունը)[cite: 3]
- Ֆիլտրել ցանկը ըստ կարգավիճակի (All / Available / Borrowed)[cite: 3]
- Տեսնել ժամկետանց (overdue) գրքերի վիզուալ ընդգծումը և վերևի վահանակի քանակային հաշվիչները (Counters)[cite: 3]

5. Which rules must the app enforce?
- Չի թույլատրվում ավելացնել գիրք առանց վերնագրի կամ հեղինակի[cite: 3].
- Արգելվում է գիրք վերցնել առանց վերցնողի անունը լրացնելու (դատարկ անունով տվյալներ չեն ընդունվում)[cite: 3].
- Արդեն վերցված (Borrowed) գիրքը չի կարող կրկնակի վերցվել մինչև չվերադարձվի (ցուցադրվում է հստակ արգելող հաղորդագրություն)[cite: 3].
- Վերցված գիրքը հնարավոր չէ ջնջել (հավելվածը պետք է արգելկի դա)[cite: 3].
- Ջնջման գործողության ժամանակ հավելվածը պետք է պահանջի հաստատում. Cancel-ը պահպանում է գիրքը, OK-ը՝ ջնջում[cite: 3].
- Ժամկետանց գրքերը պետք է ակնառու կերպով առանձնացվեն (օրինակ՝ կարմիր գույնով)[cite: 3].

6. What should the screen look like?
- Մաքուր, ժամանակակից և հարմարավետ ինտերֆեյս (Clean layout, UI/UX լավագույն պրակտիկայով)[cite: 3].
- Վերին հատվածում՝ վիճակագրական վահանակ (Counters) ընդհանուր, հասանելի, վերցված և ժամկետանց գրքերի քանակներով[cite: 3].
- Որոնման դաշտ և ֆիլտրման կոճակներ/թաբեր[cite: 3].
- Գրքերի ավելացման/խմբագրման կոմպակտ ֆորմա (Input fields)[cite: 2, 3].
- Աղյուսակ կամ քարտերի համակարգ (Grid/Table)՝ գրքերի մանրամասներով և համապատասխան գործողությունների կոճակներով (Borrow, Return, Edit, Delete)[cite: 2, 3].

7. Technical rules:
- Մեկ միասնական HTML ֆայլ (`library.html`), որի ներսում ներառված են CSS ոճերը և JavaScript տրամաբանությունը[cite: 1, 2].
- Աշխատում է տեղային բրաուզերում՝ ֆայլի վրա կրկնակի սեղմելով, առանց ինտերնետի և առանց որևէ լրացուցիչ ծրագրի տեղադրման[cite: 1, 2].
- Տվյալների պահպանումն իրականացվում է բրաուզերի `localStorage`-ի միջոցով, որպեսզի էջը փակելուց և վերաբացելուց հետո բոլոր գրքերն ու դրանց կարգավիճակները պահպանվեն[cite: 1, 3].
